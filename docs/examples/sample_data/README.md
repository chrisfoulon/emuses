# EMUSES Sample Data

## Human Connectome Project (HCP) Sample Dataset

This directory contains sample neuroimaging data from the Human Connectome Project (HCP) for demonstration and testing purposes.

### Files

- **hcp_input_data.csv**: Neuroimaging input variables (1068 subjects)
- **hcp_labels.csv**: Fluid intelligence scores (adjusted) for prediction tasks

### Data Attribution

**Source**: Human Connectome Project (HCP)  
**License**: HCP Open Access Data Use Terms  
**Citation**: 
```
Van Essen DC, Smith SM, Barch DM, Behrens TE, Yacoub E, Ugurbil K; 
WU-Minn HCP Consortium. The WU-Minn Human Connectome Project: 
an overview. Neuroimage. 2013 Oct 15;80:62-79.
```

### Usage

This data is provided for:
- Quick start tutorials and examples
- Testing EMUSES functionality
- Research workflow demonstrations

### Data Description

The dataset contains neuroimaging features and cognitive assessment scores suitable for predictive modeling tasks typical in neuroimaging research.

**Input Variables**: Selected neuroimaging features from structural and functional MRI
**Target Variable**: Fluid intelligence scores (continuous prediction task)
**Subjects**: 1068 participants from the HCP dataset

### Research Use

This sample data demonstrates typical neuroimaging prediction workflows:
1. **Individual Research**: Local analysis and model development
2. **Lab Collaboration**: Model sharing and validation across teams
3. **Community Research**: Reproducible research with public datasets

For production research, users should obtain full HCP datasets directly from the HCP project according to their data use terms.
